4. 資安能力專章（B 軌）

主管機關首度正式確認之 AI 輔助攻擊（窗內，基線遺漏補列）

CISA 會同 NSA、FBI、DOE、EPA 於約 2026-08-19 發布聯合公告 AA26-231A，警告攻擊者以 AI 生成之利用腳本（偽裝為合法監控工具）對美國關鍵基礎設施之 Siemens S7 系列 PLC 進行偵察與攻擊，涵蓋初始存取、憑證存取與阻斷服務，受影響部門包括關鍵製造、能源、水務、化工與食品農業。CISA 官網對自動抓取回應 403，發布日經 The Hacker News（08-20）等具編輯審查媒體交叉確認。證據等級：已證實。

對防守方影響 OT 環境應立即檢視 S7 PLC 之網路暴露面與存取控制；AI 生成攻擊工具偽裝為合法軟體，行為偵測與白名單管控之權重應高於特徵比對。
對攻擊方影響 主管機關正式將 AI 生成利用腳本列為現行威脅，顯示此類工具已從研究議題進入實戰部署階段。

攻擊者使用 AI 之實案（日期修正）

Gambit Security 報告之一手原文已於本次複查取得（官方部落格，原始發布 2026-08-13，屬窗前；基線所記 08-18 為 Help Net Security 轉述日）。三起案例：疑似 The Gentlemen 勒索軟體聯盟成員以 Claude Code 入侵至少六家組織；Zerofot 行動以 OpenAI Codex 與 Claude Code 打造自動掃描工具竊取金鑰；RAGE 為 AI 生成之 Python 攻擊框架用於部署挖礦程式。注意：轉述中之精確數字（2,975 組金鑰、1,742 台受害主機）僅見於完整報告與二手轉述，一手概述頁未列。證據等級：廠商主張（資安廠商一手研究，無獨立複核）。

防禦側：AI 漏洞挖掘工業化（窗內，基線遺漏補列）

Google Cloud／Mandiant 於 2026-08-18 揭露 AVDH（Agentic Vulnerability Discovery Harness）多代理漏洞挖掘管線：十個月內掃描數千萬行程式碼；在一起事件回應案件中，兩日內於失竊之企業儲存庫發現逾百個真陽性嚴重漏洞，已獲配 12 個 CVE，並公開架構藍圖。與窗前 Unit 42 之 14,090 個開源漏洞（08-04）並列，顯示攻防雙方的漏洞發現速度均進入量產階段。對防守方：可倣效架構對自有程式碼先行掃描，但通報與修補量能將成瓶頸；對攻擊方：同類管線落入攻擊者之手即為零日工廠，失竊原始碼之風險權重上升。

6. 風險與反面觀點

  • PR 動機：OpenAI 降價為限期促銷（官方頁明載至 2026-11-21），緊接競品發布，屬競爭回應；長期採購測算不應以促銷價為基準。OpenAI 零留存公告與 Anthropic 留存爭議時點重疊，帶有明顯的企業客戶爭奪意圖。
  • 商業誘因：Gambit Security 與 CrowdStrike 之報告同時服務其產品行銷；Gambit 案例之關鍵數字僅見於自家完整報告，無被害組織或主管機關獨立確認。Mandiant AVDH 成果亦為廠商自述，CVE 獲配可查證但「兩日百漏洞」之效率宣稱無第三方復現。
  • benchmark 可比性：Gemini 3.7 Flash 之 DeepSWE 分數為廠商自評；跨廠商分數不具直接可比性（參見 CrowdStrike 之 benchmaxxing 討論）。
  • 轉述失真風險：本次複查實證兩例——Gambit 報告之發布日在轉述中被誤置（08-13 被記為 08-18）；另有媒體將 Cursor 錯誤歸屬為 SpaceX 所有（08-27 期後報導）。二手來源之日期與歸屬均應回溯一手查核。
  • 獨立驗證缺口：Anthropic 留存政策調整仍無官方公告，現有資訊源自匿名消息與員工個人發言，存在測試市場反應之可能；白宮框架之覆蓋門檻列為機密、僅涵蓋閉源模型且排除 open-weight，外界無從驗證其實質約束力。
