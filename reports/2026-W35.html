4. 資安能力專章（B 軌）

攻擊者實際使用 AI 之事件揭露

Gambit Security 於 2026-08-18 發布之報告（經 Help Net Security 具編輯審查轉述）記錄三起實案：其一，勒索軟體操作者以 Claude Code 入侵六個組織，用 AI 生成偵察指令與惡意腳本，並辨識最具價值之業務系統；其二，代號 Zerofot 之憑證竊取行動以 OpenAI Codex 與 Claude Code 打造自動掃描工具，於 4 至 5 月間竊得 2,975 組驗證金鑰；其三，代號 RAGE 之挖礦框架整合 DeepSeek 作為協調器管理殭屍網路，鎖定 Redis、Elasticsearch、Docker 等服務。證據等級：第三方評論。

對防守方影響 須假設攻擊者已用 AI 自動辨識高價值資料並加速入侵流程；資料分級、憑證輪替與暴露面盤點之優先級應提高。
對攻擊方影響 現成商用 AI 編程工具已可直接支撐入侵全流程，技術門檻與行動時間同步下降。

防禦側動態

CrowdStrike 於 2026-08-17 發表以 AI 推理進行偵測告警分級（detection triage）之技術文章，並於 2026-08-19 發表討論 AI 安全基準測試被當成優化目標時失真之「benchmaxxing」議題（均為廠商部落格，Tier 3）。對防守方：SOC 分級自動化可望減輕告警疲勞，但選型不應僅看基準分數；對攻擊方：AI 防禦若針對基準過度優化，基準外盲區即為可利用之繞過空間。

6. 風險與反面觀點

  • PR 動機：OpenAI 降價為限期促銷而非結構性降價，時點緊接 Gemini 3.7 Flash 半價策略與競品發布，屬競爭回應；促銷期滿後之實際成本應以屆時價目表為準，不宜以促銷價做長期採購測算。
  • 商業誘因：Gambit Security 為資安廠商，揭露攻擊者使用 AI 之報告同時服務其產品行銷；案例真實性尚無主管機關或被害組織之獨立確認。CrowdStrike 之 Agentic SOC 系列同屬產品線鋪陳。
  • benchmark 可比性：Gemini 3.7 Flash 之 DeepSWE 分數為廠商自評，無第三方復現；「benchmaxxing」議題本身即說明基準分數可被針對性優化，跨廠商分數不具直接可比性。
  • 獨立驗證缺口：Anthropic 資料留存政策調整僅有引述匿名消息人士之媒體報導，官方未公告，存在以放話測試市場反應之可能；白宮自願性測試框架不公開評估準則與門檻，外界無從驗證其實質約束力；OpenAI 與 CISA 官網對自動抓取回應 403，本期多則事實僅能以轉述來源確認，證據等級因此受限。
